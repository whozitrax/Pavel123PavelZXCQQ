# Playerok / Deelo Bot + Mini App

- `main.py` — Telegram-бот + aiohttp Mini App server.
- `web/index.html` — Mini App.
- `web/playerok_welcome.png` — фото приветствия `/start`.
- `web/playerok_how.jpg` — фото для «Как это работает».
- `data/playerok.sqlite3` — создаётся автоматически при запуске для хранения профилей, сделок и уведомлений.

## Важно для сделок
Пользователь, которому отправляют сделку по `@username`, должен хотя бы один раз открыть бота и нажать `/start`. Это нужно Telegram, чтобы бот знал его chat ID и мог отправить уведомление.

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

Нужны переменные `BOT_TOKEN` (или `TOKEN`), а также `WEBHOOK_URL` или `DOMAIN`.


## ИИ-помощник в Mini App
Встроенный чат поддержки обновлён под сценарий из примера:
- живое приветствие «Можно просто «поддержка» или на «ты» — как удобнее»;
- контекстные ответы по верификации, выводу, сделкам, балансу и спорным ситуациям;
- для вопроса «как пройти верификацию?» показывается карточка с изображением и шагами;
- добавлена небольшая задержка «печатает…», чтобы ответы выглядели как переписка;
- ответы работают без внешнего AI API. Если `window.DEELO_AI_ENDPOINT` задан, внешний LLM endpoint по-прежнему используется.
